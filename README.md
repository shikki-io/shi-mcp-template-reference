# shi-mcp-template-reference MCP Server

Generated by `shi-agency mcp new shi-mcp-template-reference` — W7 customer MCP scaffolder.

## Requirements

- Swift 6.0+
- macOS 14.0+

## Build

```sh
swift build --product shi-mcp-template-reference
```

## Run

```sh
.build/debug/shi-mcp-template-reference
```

## Add to Claude Desktop

```sh
claude mcp add shi-mcp-template-reference .build/debug/shi-mcp-template-reference
```

Then run `tools/list` to see registered tools. The sample `shi-mcp-template-reference_ping` tool is
pre-registered and responds immediately.

## Add customer tools

1. Conform a `struct` to `MCPTool` (see `Sources/shi-mcp-template-referenceSampleTool/SampleTool.swift`).
2. Register it in `Sources/shi-mcp-template-reference/main.swift` via `server.register(MyTool())`.
3. Optionally pull `ShikkiMCPPostgresKit` or `ShikkiMCPDBToolsKit` from the shikki
   monorepo for Postgres-backed tools.
